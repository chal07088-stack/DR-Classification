# Reports

This folder separates the project results into three report tracks.

## 1. Ours Proposed

Use `ours_proposed.md` for the proposed method, ablation studies, and internal experiment variants.

## 2. Official-Setting Comparison

Use `official_setting_comparison.md` for external comparator results where each paper keeps its official hyperparameters as much as possible.

## 3. Unified-Setting Comparison

Use `unified_setting_comparison.md` for controlled comparison where compatible methods are rerun under the common project hyperparameter protocol.
