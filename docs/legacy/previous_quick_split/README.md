# Previous Quick20 split (legacy)

These files are preserved only for provenance and recovery.

They were the active Quick20 split before `quick20_symmetry_preserved_v2`. They must not be used for new benchmark training, evaluation, model selection, or claims because the old workflow did not encode the full-population Symmetric:Asymmetric ratio as the explicit primary allocation constraint.

The old model outputs and checkpoints remain preserved in their original legacy result directories. New runners write to split-versioned paths and cannot silently reuse or overwrite them.
